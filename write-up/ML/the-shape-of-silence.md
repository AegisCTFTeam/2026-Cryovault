Flag: `isfcr{577027585a0778773aa949d9}`
1. 문제 구성
`unlock.py`: 24개 출력 리스트를 JSON(`separators=(',',':')`)으로 직렬화 → `sha256(b'isfcr-ml\0' + enc)`를 키로 AES-GCM 복호화. 정답 리스트를 바이트 단위로 정확히 맞춰야 함.
`data.json`
`model_version`: 현재 모델 `v-8fb4ff`
`captures` 22개: 각각 7개 점으로 된 cloud 2개 (6차원 입력 `x`, 출력 `y`, 모두 분수 문자열)
`anchors` 16개: 현재 모델의 정답 (x, y) 쌍 → 검증용
`targets` 24개: 출력을 구해야 할 입력
> 함정: capture 중 4개는 `v-41e59d`(구버전 모델)이다. **현재 모델(`v-8fb4ff`) 캡처 18개만 사용**해야 한다.
2. 핵심 관찰 — cloud 하나는 정확히 선형
cloud 내 7개 점은 서로 매우 가깝다(표준편차 ~0.005). 각 cloud에 `y = w·x + b`를 최소제곱으로 맞추면 잔차가 0이고 계수가 전부 정수다.
→ 모델은 조각별 선형(piecewise linear) 함수, 즉 ReLU 네트워크이며 각 cloud는 하나의 선형 영역 안에 있다.
현재 모델에서 서로 다른 선형 조각 32개를 얻는다.
3. cloud 쌍의 차이 = 뉴런 하나
같은 capture의 두 cloud는 뉴런 하나의 경계를 사이에 두고 놓여 있다. 따라서 두 조각의 차이 `p2 - p1`이 그 뉴런의 기여 `a_j·(w_j, b_j)`가 된다.
이렇게 서로 다른 뉴런 벡터 9개를 추출했다 (각 7성분 = 6개 가중치 + bias):
```
V1 = [-10,  2,  4, -10,   2,   8,   6]
V2 = [  4, -4, -4,  -8,  -8,  -2,  -6]
V3 = [ -4,-20, -8,   4, -16,  12, -28]
V4 = [  4, -8, -8,  -8,   8,  16,  16]
V5 = [ -4, -8,-20, -16,   4, -20,  12]
V6 = [ -3, -6,  9,  -9,   9,   6, -15]
V7 = [ -4,  1, -4,   4,   3,  -1,   4]
V8 = [ -8, 12,  4,   4, -20, -12,  16]
V9 = [  8,  2, 10,   4,  10,   4,  -6]
```
4. 은닉층 1개 구조 확인
모든 조각이 `c + Σ t_j·V_j` (t_j ∈ {0,1}) 꼴인지 2⁹ 조합으로 검사했다.
공통 상수 `c = [-3,-2,-5,0,1,-5,0]`일 때 32개 조각 전부 일치.
5. 활성 방향 결정
각 cloud에서 `z_j = V_j·[x,1]`의 부호와 t_j를 비교한다.
V6, V9를 제외한 7개 뉴런: `t_j=1 ⇔ z_j>0` → `max(0, z)`
V6, V9: `t_j=1 ⇔ z_j<0` → `min(0, z)` (V를 음수로 뒤집은 ReLU와 동치)
최종 모델:
```
y = c·[x,1] + Σ_j  max(0, V_j·[x,1])     (j = 6, 9는 min(0, ·))
```
anchors 16개 검증 → 오차 정확히 0.
6. 타깃 계산과 제출 형식
`Fraction`으로 정확히 계산한 뒤, 데이터와 같은 분수 문자열 형식(`"5441/64"`, 정수는 `"26"`)으로 제출해야 한다. float로 넣으면 JSON 직렬화가 달라져 키가 틀리고 `Rejected.`가 나온다.

7. Solver
```python
import json, sys
from fractions import Fraction as F
from unlock import unlock

d = json.load(open('data.json'))
V = [[-10,2,4,-10,2,8,6],[4,-4,-4,-8,-8,-2,-6],[-4,-20,-8,4,-16,12,-28],
     [4,-8,-8,-8,8,16,16],[-4,-8,-20,-16,4,-20,12],[-3,-6,9,-9,9,6,-15],
     [-4,1,-4,4,3,-1,4],[-8,12,4,4,-20,-12,16],[8,2,10,4,10,4,-6]]
c   = [-3,-2,-5,0,1,-5,0]
sgn = [1,1,1,1,1,-1,1,1,-1]

def model(x):
    xt = [F(v) for v in x] + [F(1)]
    dot = lambda w: sum(a*b for a, b in zip(w, xt))
    return dot(c) + sum(max(0, dot(v)) if s == 1 else min(0, dot(v))
                        for v, s in zip(V, sgn))

assert all(model(a['x']) == F(a['y']) for a in d['anchors'])
ans = [str(model(t)) for t in d['targets']]
print(unlock(ans))   # isfcr{577027585a0778773aa949d9}
```
요약
"국소적으로 정확히 선형"이라는 점을 이용해 cloud마다 선형 조각을 복원하고, 경계를 사이에 둔 cloud 쌍의 차이로 뉴런을 하나씩 추출했다. 이는 ReLU 네트워크에 대한 cryptanalytic model extraction 공격의 축소판이다. 구버전 캡처를 걸러내는 것과 출력 형식을 분수 문자열로 맞추는 것이 마지막 함정이었다.
